# Golden M

Golden M is a software and hardware company building Layrz, our IoT-specialized platform for interconnecting, processing, and exporting data from anywhere. Today Layrz monitors 24,000+ assets for over 12,000 users globally — turning raw telemetry into the information businesses actually need.

## Open Source

We accept contributions to our open-source libraries. Please check each repository's `CONTRIBUTING.md` and issue templates before opening a PR — for larger changes, opening an issue first helps us align on direction, since these libraries are maintained as part of Layrz's own production stack.

**Find our packages on:**
- Dart/Flutter — [pub.dev/publishers/layrz.com](https://pub.dev/publishers/layrz.com) · [pub.dev/publishers/goldenm.com](https://pub.dev/publishers/goldenm.com)
- Python — [pypi.org/user/layrz-software](https://pypi.org/user/layrz-software/) · [pypi.org/user/goldenm-software](https://pypi.org/user/goldenm-software/)
- Node — [npmjs.com/~goldenm](https://www.npmjs.com/~goldenm)
- Ruby — [rubygems.org/profiles/goldenm](https://rubygems.org/profiles/goldenm)

### Flutter/Dart — UI & device libraries

| Repo | Description |
|---|---|
| [layrz_theme](https://github.com/goldenm-software/layrz_theme) | Layrz standard theme library for Flutter, based on Material You (Material 3) |
| [layrz_ui](https://github.com/goldenm-software/layrz_ui) | Drop-in replacement for layrz_theme (experimental) |
| [layrz_icons](https://github.com/goldenm-software/layrz_icons) | Unified icon system for Flutter |
| [layrz_models](https://github.com/goldenm-software/layrz_models) | Layrz API models for Dart/Flutter |
| [layrz_logging](https://github.com/goldenm-software/layrz_logging) | Logging system for Flutter applications |
| [layrz_nfc](https://github.com/goldenm-software/layrz_nfc) | NFC card interaction for Flutter |
| [layrz_wifi](https://github.com/goldenm-software/layrz_wifi) | Scan nearby WiFi networks / read SSID across platforms |
| [layrz_ble](https://github.com/goldenm-software/layrz_ble) / [layrz_ble_dart](https://github.com/goldenm-software/layrz_ble_dart) | BLE device interaction for Flutter |

### Protocol & scripting SDKs

| Repo | Description |
|---|---|
| [layrz-protocol](https://github.com/goldenm-software/layrz-protocol) | Layrz Protocol monorepo — translate packages sent/received by the Layrz Protocol |
| [layrz-sdk](https://github.com/goldenm-software/layrz-sdk) | SDK for Layrz scripting and related topics (not an API connector) |
| [layrz-forms](https://github.com/goldenm-software/layrz-forms) | Form tools to validate structured data |
